# Execution journal

> Session-by-session diary of the build: what happened, deviations from the plan, setup gotchas, and loose ends to pick up next session. Newest entry first.
>
> **What does NOT go here** — this file competes with nothing:
> - Decisions about what the system is → `core/` (new/updated AD, RF, RN, DP by ID).
> - Bugs that revealed something about the system → `doc-ai/bugs/`.
> - Phase/sub-task completion state → checked off in `plan.md`.
